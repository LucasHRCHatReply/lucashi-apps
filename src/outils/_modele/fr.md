Ce fichier est le modèle d'une fiche d'outil. Le texte ci-dessous illustre le gabarit : 300 à 700 mots utiles dans une vraie fiche, jamais de remplissage.

## Comment faire

1. Collez votre texte dans la zone, ou déposez un fichier texte.
2. Lisez le résultat : il se met à jour à chaque frappe.
3. Copiez le résumé, ou téléchargez-le.

## Pourquoi c'est privé

Le calcul se fait dans votre navigateur. Aucun texte ne quitte votre appareil, et aucun compte n'est demandé.
