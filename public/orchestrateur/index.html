Ce qui n’est pas encore mesuré : le code difficile confié à GPT ou Gemini, Fable ou Opus en orchestratrice, le très long contexte. Le skill le dit, il ne le devine pas.

Avant d’installer.

C’est payant ?

Non. Le skill est gratuit et ses fichiers sont lisibles.

Faut-il GPT ou Gemini ?

Non. Sans eux, tout reste sur Claude. Avec eux, le skill vérifie d’abord votre quota et refuse s’il est trop bas.

Ça marche avec un abonnement Claude ?

Oui. Les économies sont calculées aux prix de l’API : sur un abonnement, elles se traduisent en limites qui durent plus longtemps, pas en euros.

Sur quoi ça tourne ?

macOS, Claude Code (de préférence l’app de bureau, onglet Code), Node 18 ou plus.

Mes données partent-elles quelque part ?

Le plugin n’envoie rien. La version zip propose, le 1er du mois, un partage de chiffres anonymes ; rien ne part sans un clic sur « Partager ».

Comment je m’en sers ?

Écrivez « orchestre ce chantier : … » ou /orchestrateur. Le skill se déclenche aussi seul quand vous demandez de lancer ou de répartir du travail.

Installer

Deux commandes. Votre prochaine demande est orchestrée.

Dans Claude Code, tapez la première ligne, puis la seconde.

/plugin marketplace add LucasHRCHatReply/orchestrateur-releases
/plugin install orchestrateur@orchestration
  1. Téléchargez le zip si vous voulez le lire avant, ou lancez la commande : elle télécharge, vérifie l’empreinte, décompresse et installe.
  2. Version 3.0.0. L’empreinte SHA-256 est vérifiée avant toute installation.

SHA-256 : lue dans orchestrateur.zip.sha256, à côté du zip

⬇︎ Télécharger orchestrateur.zip
  1. Copiez le prompt, collez-le dans Claude Code (l’app de bureau, onglet Code, ou claude dans un terminal).
  2. Claude télécharge, lit le script, demande votre accord, installe.

Ensuite, dites simplement : « orchestre ce chantier : … »
